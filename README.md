# CodeAlpha_Sales_Prediction

CodeAlpha Data Science Internship — Task 4.

Predicts sales from advertising spend (TV, Radio, Newspaper) using:
- A `LinearRegression` baseline (scikit-learn)
- A feed-forward neural network trained on GPU (PyTorch + CUDA)

## Run

```
cd CodeAlpha_Sales_Prediction
jupyter notebook sales_prediction.ipynb
```

Select the **Python 3 (CodeAlpha DS)** kernel.

## Dataset

`data/Advertising.csv` —
[Kaggle: bumba5341/advertisingcsv](https://www.kaggle.com/datasets/bumba5341/advertisingcsv)
